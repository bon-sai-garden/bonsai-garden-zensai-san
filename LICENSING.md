# Licensing

## The map

### Apache License 2.0: our code, wherever it sits

- **`agents/zensai-san/scripts/integrity/check.py`**: his integrity check, the one script he ships. It is generated by the garden's builder, written into this repository and committed, so what you read here is what ships. It opens with a copyright line and `SPDX-License-Identifier: Apache-2.0`.
- **Templates and styles.** `agents/zensai-san/assets/greeting.html` (the card template a room fills) and the stylesheet and markup structure of `agents/zensai-san/references/heritage.html` (his witnesses' page) are code, and Apache 2.0. The words inside them are not: see below. If a page of his ever carries a script, the script is Apache 2.0 as well.
- **Data a script reads, and the generated files that carry no words of ours:** `agents/zensai-san/agents/registry.json` (the package marker), `agents/zensai-san/identity/registry-entry.json`, `agents/zensai-san/identity/marks.json`, `.gitignore`.
- **Seals and identity data:** every `.bonsaisig`, and the public key, its text copy and its fingerprint under `agents/zensai-san/identity/`. They are published so that anyone can check a signature.

### CC BY-SA 4.0: our words, rites and procedures, and the rest that is not code

- **Persona and constitution:** `agents/zensai-san/SKILL.md`, `references/about-me.md`, `references/procedures/`, `references/lineage.md`, `references/credits.md`, `references/changelog.md`, `references/integrity.md` (the words that describe his check), the words of `assets/greeting.html` and `references/heritage.html`, `assets/codex.md`, `assets/human-covenant.md`, `assets/intro.md`, `assets/greeting.txt`, `memory/`, `identity/bunshin-attestation.md`.

The mark, `assets/zensai-san-mark.svg`, is drawn in KanjiVG strokes and is **CC BY-SA 3.0 Unported**, as its own `<desc>` says, or a later version with the same terms; `LICENSE-CC-BY-SA-4.0` is that version.
- **Every document of this repository:** `README.md`, `AGENTS.md`, `CLAUDE.md` and `CREDITS.md` (these four stay in the repository; the skill does not carry them) and this page.

ShareAlike asks that an adaptation of these go out under the same licence, or one the licence names as compatible.

### Third-party material

It keeps its own licence, and `agents/zensai-san/references/credits.md` names each (the repository's `CREDITS.md` only points there): Wikipedia (CC BY-SA 4.0), KanjiVG (CC BY-SA 3.0 Unported) and KANJIDIC2 (CC BY-SA 4.0). This page relicenses none of it.

## Where a file is mixed

**The file's own use decides.** A page that is a template or a stylesheet is code in its structure and its styles, and a document in its words: the two parts keep their two licences. A document that quotes code stays a document. If a file cannot be placed by this page, that is a bug in this page: say so, and the file gets a header that names its licence.
